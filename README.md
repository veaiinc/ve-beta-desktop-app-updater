# VE Dashboard V1

This project is a Vite-based React application for the Ve.ai dashboard.

## Prerequisites

-   Node.js >= 18

## Available Scripts

In the project directory, run:

### `npm install`

Install dependencies.

### `npm start`

Run the app in development mode. Open [http://localhost:5173](http://localhost:5173) to view it. The page reloads on changes.

### `npm test`

Run tests with Vitest.

### `npm run build`

Build the app for production to the `build` folder. The build is minified for best performance.

### `npm run preview`

Preview the production build locally.

### `npm run format`

Format code using Prettier.

### `npm run delete-maps`

Delete source maps from the production build.

## Configuration

Environment variables are loaded from the `.env` file. To override for local development, create a file named `.env.local` alongside `.env`.
