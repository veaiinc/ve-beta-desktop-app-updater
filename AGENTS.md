# Repo guidelines

This repo is a Vite-based React project.

-   Always run `npm run format` before committing to ensure Prettier formatting.
-   Prettier settings are defined in `package.json` (printWidth 100, trailing commas, tab width 4, semicolons, single quotes, tabs for indentation).
-   Run `npm run build` to ensure that the project builds without errors. There are no automated tests.
-   Do not commit `build` or `dist` directories.
-   Update `README.md` when adding new dependencies or scripts.
