## 🔧 Installation Process

### **For NSIS Installer:**

```
1. User downloads: Ve.AI-x64-win.exe
2. Double-clicks the file
3. Windows shows: "Do you want to allow this app to make changes?"
4. User clicks: "Yes"
5. Installer wizard opens:

┌─────────────────────────────────────────────────────────────┐
│                    Ve AI Setup                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Welcome to Ve AI Desktop App Setup                        │
│                                                             │
│  This will install Ve AI Desktop App on your computer.     │
│                                                             │
│  Click Next to continue, or Cancel to exit Setup.          │
│                                                             │
│                    [Cancel]  [Next >]                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘

6. User clicks "Next"
7. Installation completes
8. App appears in Start Menu
9. Desktop shortcut created (optional)
```

### **For Portable Version:**

```
1. User downloads: Ve.AI-x64-win-portable.exe
2. Places file in desired folder (Desktop, Documents, etc.)
3. Double-clicks to run
4. App starts immediately - no installation needed
5. Can be moved to USB drive or any location
```
